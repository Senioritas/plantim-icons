# Custom Plant Icons

Plantim custom icon family extending Lucide Icons.

## Style Guide

- Grid: 24×24px viewBox
- Stroke width: 2px (`stroke-width="2"`)
- Caps/joins: round (`stroke-linecap="round" stroke-linejoin="round"`)
- Fill: none (stroke-only)
- Color: `stroke="currentColor"` (inherits from CSS)
