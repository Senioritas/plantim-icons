# Plantim brand marks — an asset class, not semantic icons

`brand.*` ships the Plantim logo and the three identity providers the Plantim
apps offer for sign-in. Like [flags](../flags/README.md), brand marks cannot
honour the v4 icon contract: their colours belong to their owners, an outline
logo is meaningless, and the third-party marks may not be redrawn at all. So
they get their own DSL, renderer, registry and gate.

| id | owner | grades | light / dark colour |
| --- | --- | --- | --- |
| `brand.plantim` | Plantim | micro, base, display (traced) | `#30963B` / `#30963B` |
| `brand.google` | Google LLC | one geometry | four-colour G, fixed |
| `brand.github` | GitHub, Inc. | one geometry | `#181717` / `#FFFFFF` |
| `brand.apple` | Apple Inc. | one geometry | `#000000` / `#FFFFFF` |

## Variants and sizes

Static SVGs ship in three variants: `color` (light surfaces), `color.dark`
(dark surfaces; identical to `color` unless the owner publishes a dark colour)
and `mono` (every layer in `currentColor`). The Vue component and the SwiftUI
view expose `color` plus a theme instead: `theme="dark"` on the web, and
`colorScheme` on iOS.

Sizes are the six v4 sizes plus 96, 128, 192, 256 and 512 px, all of the
larger ones on the display grade, so one source covers tab bars, sign-in
buttons, splash screens, hero panels and favicons.

## The Plantim logo

The geometry is traced from [`tools/plantim-logo.png`](tools/plantim-logo.png),
the artwork the product uses, and never reinterpreted.

- **display (48 px and up)** is the full logo: every trunk strand, twig, root
  and leaf vein.
- **base (24, 32)** and **micro (16, 20)** keep the same silhouette. The logo's
  hairline gaps are 0.2–0.4 grid units wide, below one device pixel at these
  sizes, so they are closed and the main ones are cut back in wide enough to
  render: the leaf outline, the midrib and veins, the crescent and the trunk
  strands. Roots and twigs keep their original shape.

The grades are defined in [`tools/plantim-grades.json`](tools/plantim-grades.json)
(see [`tools/rasterize.py`](tools/rasterize.py) for what each setting does).
To change them, edit the JSON and run:

```sh
npm run icons:brand:trace   # needs python3 + Pillow and potrace
npm run icons:brand
```

The trace writes `src/plantim-geometry.mjs`, which is committed and reviewed
like any other authored geometry. The build never runs the tracer.

## Third-party marks

`src/brand.mjs` keeps the published Google, GitHub and Apple artwork verbatim
in its own viewBox; `fit()` only scales and centres it into the 20×20 live
area. Never edit those path strings, recolour them or build variants beyond
`mono`. Use them only in sign-in buttons and linked-account rows, following
each owner's guidelines. They are not covered by the MIT license; see
[`TRADEMARKS.md`](../../../TRADEMARKS.md).

## Layout

```
brand/
  README.md
  src/brand.mjs              definitions (DSL: design-tokens/bin/lib/brand-dsl.mjs)
  src/plantim-geometry.mjs   traced Plantim logo grades (generated by tools/)
  tools/                     source logo, grade settings and the tracer
  registry.brand.json        compiled, self-hashed (generated)
  index.brand.json           manifest (generated)
  svg/<variant>/<id>@<size>.svg   3 variants × 11 sizes per mark (generated)
```

## Commands

```sh
npm run icons:brand          # generate + gate + npm subpath + SwiftUI adapter
npm run icons:brand:check    # structural gate only
npm run icons:brand:test     # Vue component vs generated SVG parity
```

## Rules (enforced by `check-brand-icons.mjs`)

- Hash integrity and deterministic regeneration.
- Ids are `brand.<lowercase name>` and never collide with an icon or flag id.
- Geometry stays on the 24-grid live area (1 px overshoot), at most 3 decimals.
- Colours are uppercase 6-digit hex; `color` variants never use `currentColor`
  and `mono` fills every layer with it. Marks are filled, never stroked.
- Every mark names an owner and permitted usage, and every owner is listed in
  `TRADEMARKS.md`.
- Every mark has an accessible name in every locale under `locales/`.

## Adding a mark

One `brand()` call in `src/brand.mjs`, a label in every locale, the owner in
`TRADEMARKS.md`, then `npm run icons:brand`.
